## ✈ Highlights & Features

- **Sequential Flow HUD Interface**: Smooth progression from **01 HOME** ➔ **02 FLEET** ➔ **03 TEAM** with dynamic cosmic starfield, nebula particle canvas, and reading telemetry bar.
- **Mission UAV Fleet**:
  - **Drishti**: Autonomous surveillance quadcopter with 3-axis gyro-stabilized gimbal, thermal imaging, and AI target lock.
  - **Rakshak**: Heavy-lift carbon fiber hexacopter with 2.0 kg payload capacity and servo-actuated precision drop bay.
  - **Sagar**: Amphibious water rescue quadcopter with IP67 waterproofing and rapid life-buoy deployment mechanism.
- **Flight Squadron Command**:
  - Executive Leadership Triangle with custom aerodynamic V-crest geometry.
  - 13 Specialized Technical Domains (Airframe, Avionics, Autonomous Navigation, Computer Vision, Simulation, GCS, Propulsion, Payload, Tooling, CAD, Social Media, Doc & Sponsorship).
- **Interactive Multi-Cohort Roster**: Dynamic cohort selector for 2026 and 2025.
- **Backend Transmission API**: Express-based Node.js backend handling telemetry health checks and sponsorship inquiry transmissions.

## 🚀 Quick Start (Local Development)

### Prerequisites
- Node.js (v18+)

### Installation & Run

1. Clone repository:
   ```bash
   git clone https://github.com/ahrkive/vayu.git
   cd vayu
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch Flight Ops Server:
   ```bash
   npm start
   ```

4. Open browser at [http://localhost:3000](http://localhost:3000).

## 🌐 GitHub Pages Deployment

This repository is optimized for **GitHub Pages**. The root `index.html` seamlessly serves all assets, styles, and scripts statically without needing a server build.

To enable GitHub Pages:
1. Go to repository **Settings** ➔ **Pages**.
2. Under **Build and deployment**, select:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `root`
3. Click **Save**. Your site will be live at:
   `https://ahrkive.github.io/vayu/`
